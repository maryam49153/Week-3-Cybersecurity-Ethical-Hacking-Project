1. Project Overview

This project focused on understanding password security, PDF password protection, and the role of password recovery tools in authorized cybersecurity testing.

Two essential project modules were completed using John the Ripper (JTR), Johnny GUI, and NetworkWalks online tools.

2. Objectives

Understand the fundamentals of password security.

Explore John the Ripper and its graphical interface, Johnny.

Understand PDF password hash extraction.

Explore NetworkWalks Hash Calculator and Password Cracker.

Observe how password complexity affects file security.

Understand the importance of strong password practices.
